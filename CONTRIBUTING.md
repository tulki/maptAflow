# Contributing to maptAflow

Big goals become doable when they are split into small steps.
Contributing works the same way: you do not need to understand the whole project to help with one leaf.

## Ways to help

- **Report a bug.** Open an issue: what you did, what you expected, what happened.
- **Suggest an idea.** Open an issue with the `idea` label and explain the problem it solves.
- **Improve the docs.** Typos and unclear sentences count. See `README.md` and `docs/`.
- **Write code.** Pick an open issue or open one first, so we agree before you start.

## How to send a change

1. Fork the repository.
2. Create a branch: `git checkout -b fix/short-name` or `feature/short-name`.
3. Make one change per branch and keep commits small and clear.
4. Push the branch and open a pull request to `main`.
5. In the pull request, say **what** you changed and **why**.

The maintainer reviews every pull request and may ask for changes. That is normal.

## Project setup

The stack is Rust + Tauri (desktop), SolidJS (UI), PixiJS (tree rendering) and SQLite (local storage).
See `docs/tech.md` for details.
